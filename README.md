Jitter is a custom Application-Specific Integrated Circuit (ASIC) True Random Number Generator (TRNG) designed for the Hack Club ASIC program. It is manufactured via Tiny Tapeout on the GlobalFoundries 180nm (GF180MCU) process.

Unlike software-based Pseudo-Random Number Generators (PRNGs) that rely on deterministic algorithms, this design generates true randomness by leveraging the physical characteristics of the silicon.

## How It Works

The design relies on three fundamental hardware concepts:

1. **Ring Oscillator**: The core of the design is a feedback loop consisting of an odd number of digital inverters (NOT gates). Because the number of stages is odd, the signal cannot settle into a stable state, causing it to oscillate continuously.
2. **Physical Entropy (Jitter)**: In physical hardware, this oscillation is not perfectly periodic. Microscopic manufacturing variations, thermal noise, and voltage fluctuations cause the timing of the oscillator's signal edges to fluctuate. This timing instability is known as jitter, which is fundamentally unpredictable.
3. **Sampler (Entropy Extraction)**: The oscillating signal is fed into the data input of a D Flip-Flop. The Flip-Flop is clocked by the main, stable ASIC clock. Because the ring oscillator is asynchronous to the main clock, the Flip-Flop captures the oscillator's state at a random point in its cycle, yielding a truly random binary value.

These random bits are shifted into an 8-bit register over eight clock cycles, producing a random byte output.

## Pinout and Usage

The design is configured for straightforward integration. 

| Pin Name | Direction | Description |
| :--- | :---: | :--- |
| `clk` | Input | Main ASIC clock. Used to sample the oscillator state. |
| `rst_n` | Input | Active-low reset. Drives the output register to zero when low. |
| `ui_in[0]` | Input | TRNG Enable. When high, the ring oscillator is active. When low, the oscillator is disabled to conserve power. |
| `uo_out[7:0]`| Output | Random Byte Output. Provides the latest 8-bit random value generated by the sampler. |

*Note: Unused input and bidirectional pins are tied to ground or disabled to prevent floating states.*

## Simulation and Testing

The design is verified using a `cocotb` (Python-based) testbench. The simulation validates:
- Correct reset behavior of the output register.
- Proper shifting of the 8-bit register on each clock cycle.
- Oscillator activity and output generation when the enable pin is asserted.

## Project Context

This chip was designed and verified as part of the Hack Club ASIC initiative, taped out on a shared multi-project wafer (MPW) via Tiny Tapeout. In accordance with the program's educational guidelines, all Verilog logic was written and verified manually to ensure a thorough understanding of digital hardware design principles.
